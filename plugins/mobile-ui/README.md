# Mobile UI Plugin

Mobile UI work is delivered through approved numbered vertical slices under `apps/mobile`.

Required review areas:

- Expo and React Native compatibility
- mobile accessibility
- loading, empty, error, offline and stale states
- secure token and device storage
- deep links and notification routing
- Android and iOS behaviour
- EAS build and update compatibility

This plugin does not change PES authority, intake, planning, certification, merge or release controls.
